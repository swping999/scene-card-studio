# v0.6 landscape gallery · new visual mechanisms and media

This gallery adds one Narrative System, ten production Expression Profiles, and one experimental Profile. All published sources are fictional AI-generated landscapes or objects made for this repository. No third-party photographs, prompts, style assets, named artists, studios, games, films, or publications were used.

The featured **Material Narratives** set contains `gouache-place-study`, `sculpted-place-diorama`, `threaded-landscape`, and `paper-relief-landscape`. Each remains a complete evidence-backed Before/After case in the gallery rather than a detached inspiration image.

Journey Taxonomy borrows only the general, unprotectable mechanism of semantic classification. Its rules explicitly reject the supplied social reference's palette, top/bottom duplicate photograph, white sticker outlines, vertical sticker arrangement, connector lines, and caption placement.

Threaded Landscape uses only general textile processes—woven ground, embroidery, needle felting, and selective tufting. It rejects the supplied social reference's split comparison, fringe, handwritten slogan, loose yarn props, and character arrangement.

Run `python examples/cases/v0.6-gallery/build_evidence.py --check` to verify the 12 Scene Cards and Prompt Manifests.

## 中文说明

这组画廊新增 1 个叙事系统、10 个正式表达 Profile 和 1 个实验 Profile。首页案例全部采用专为仓库生成的虚构风景或物件，不使用第三方照片、提示词、风格资产或具名创作者参考。

首页重点展示的 **Material Narratives／材质叙事精选** 包含 `gouache-place-study`、`sculpted-place-diorama`、`threaded-landscape` 与 `paper-relief-landscape`。四张图都保留为具备 Before、After、Scene Card 与 Prompt Manifest 的完整案例，而不是脱离证据链的灵感图。

Journey Taxonomy 只借鉴“按语义分类可见旅行元素”这一通用机制，明确禁止复制参考图的配色、上下重复照片、白色贴纸边缘、竖向排列、连接线与标题位置。

Threaded Landscape 只使用编织、刺绣、针毡与局部簇绒这些通用纤维工艺，明确禁止复制参考图的上下对照、流苏、手写标题、散落毛线道具和人物排列。
